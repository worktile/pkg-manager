@worktile/pkg-manager 是一款简单实用的包管理工具，主要提供自动升级版本，并发布类库等功能。核心提供了 wpm 命令行，包含以下子命令：
  • wpm release：修改版本号、生成更新日志、创建 Release 分支、提交代码到远程分支的功能
  • wpm publish：主要提供发布版本（只有类库项目才会需要）和创建Tag推送到远程仓储
  • wpm git-publish：主要提供发布代码到 GitHub 仓储的功能，目前推荐使用 GitHub Package 功能进行私有包管理

从 0.2.0-next.0 开始，wpm release 支持 Monorepo 仓库：在配置中声明 packages 后，可以一次性完成多个子包的版本号更新、更新日志生成与提交；配合多份配置文件和 --config，还支持整仓发布、按包独立发布或自定义分组发布，详见 Monorepo 发布。

安装

执行如下命令安装pkg-manager

base
npm i @worktile/pkg-manager --save-dev
base
yarn add @worktile/pkg-manager -D
base
$ pnpm add @worktile/pkg-manager -D
 
bash


安装后在 package.json 中添加如下脚本：

```json
{
  scripts: {
    ...
    "release": "wpm release",
    "pub": "wpm publish"
    ...
  }  
}

配置

每个子命令都会有不同的参数设置，可以执行命令的时候传参 wpm release --skip.bump，也可以在 .wpmrc 文件中配置。

js
module.exports = {
    allowBranch: ['master', 'v0.*'],
    bumpFiles: [
        'package.json',
        'package-lock.json',
        {
            filename: './VERSION.txt',
            type: 'plain-text'
        },
        {
            filename: './src/version.json',
            type: 'json'
        },
        {
            filename: './src/version.ts',
            type: 'code'
        }
    ],
    skip: {
        changelog: true
    },
    commitAll: true,
    hooks: {
        prepublish: 'pnpm run -r build',
        postpublish: 'lerna publish from-git',
        postreleaseBranch: 'lerna version {{version}} && git add .'
    }
};
